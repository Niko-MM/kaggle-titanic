# Titanic

Задача: угадать, выжил пассажир или нет. На Kaggle считают accuracy.

На тест уехал ансамбль: случайный лес, XGBoost и CatBoost, мягкое голосование. Остальные модели на тех же колонках были хуже: смотрел среднее и разброс по фолдам.
На Kaggle получилось 0.7822.
Все прогоны лежат в `outputs/results.txt`.

## Запуск

Скачать `train.csv` и `test.csv` в папку `data/` со страницы соревнования:
https://www.kaggle.com/competitions/titanic

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Команда из корня проекта.

Сейчас `main.py` пишет файл ответа. Ансамбль учится на всех пассажирах из train и сохраняет `outputs/submission.csv`.

Чтобы прогнать модель по 5 фолдам и дописать журнал, внизу `main.py` раскоментируй `run_cv_txt` и закомментируй `write_submission`. Обратно так же. Одна из этих строк всегда выключена. В журнал попадают среднее и разброс accuracy. Строка дописывается в `outputs/results.txt`, та же запись лежит в `outputs/results.csv`.

Сейчас в строке `model = ...` стоит ансамбль. Сеть лежит в своём модуле. Её подключают так же: импорт в `main.py` и подстановка в эту строку над двумя вызовами. Так же ставится любая другая модель с `fit` и `predict`.

Seed, число фолдов, имя прогона и списки колонок лежат в `config.py`.

Ноутбук `titanic.ipynb` — графики и разведка данных.
